# ARCore Geospatial VPS & GNSS Evaluation

This repository contains the practical implementation of my Master's Thesis, focusing on empirical accuracy evaluations comparing standard mobile GNSS positioning with the ARCore Geospatial API (Visual Positioning System).

### 🌍 Project Overview
The application serves as a spatial telemetry and measurement tool. It processes real-world geospatial data (integrated with QGIS models) and renders AR overlays to evaluate positional drift and spatial accuracy across both stationary and dynamic scenarios. 

### 🛠️ Tech Stack & Core Systems
*   **Spatial Computing & AR:** Unity 3D, AR Foundation, ARCore Geospatial API
*   **GIS & Data Integration:** QGIS mapping and real-world coordinate alignment
*   **Language:** C#
*   **Focus Areas:** Telemetry data logging, real-time spatial tracking, geospatial coordinate transformations (Latitude/Longitude to Unity World Space).
